# airflow-pyspark-etl-finance
End-to-end Airflow + PySpark ETL on the AdventureWorks dataset, building Bronze/Silver/Gold layers in Parquet with reusable Spark libs, data quality checks, pytest coverage, and finance-focused dimensional models (e.g., DimDate, DimCustomer) for downstream analytics
